## Lucide Static 1.62.0

Tool controls use selected official Lucide SVG assets.
Source: https://lucide.dev and https://github.com/lucide-icons/lucide
Distribution: npm lucide-static 1.62.0

The original ISC license is preserved in
`images/icons/lucide/LICENSE.txt`. Package version, source, and published
SHA-512 integrity metadata are preserved in `images/icons/lucide/SOURCE.json`.
SVGs are rendered with a fixed dark stroke color. Cursor highlighting, fade-status
indicators and dark-board previews add application-specific visual cues.
The supplied main logo and filled ink-size samples are separate app assets.
