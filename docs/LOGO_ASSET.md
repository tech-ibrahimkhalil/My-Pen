# Main logo

Active asset: images/app/my_pen_icon.png
Original reference: images/app/my_pen_icon.jpg

The built-in image editing tool produced the transparent PNG from the supplied JPG.
Edit prompt: remove all opaque gray square background outside the luminous green
circular ring; use genuine alpha transparency; retain the complete green ring,
dark circular interior, white pen nib and circuit detail. No added text.
The app loads the PNG for its logo/window icon. Transparent-corner validation is
included in the regression suite. No image-generation dependency is needed at runtime.
